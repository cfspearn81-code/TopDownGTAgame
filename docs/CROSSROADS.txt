DEAD CHANNEL / PORT VANTA CROSSROADS
Combined Conversation Hold + Outer Loop + Base Village

Upstream compatibility: the Conversation Hold Hotfix at
6e45643551538dcfcde018035619352c17ba0729 retains Vault 39, the
Mika/Ivo service and rear room, public NPC hold, compact pistol
pose, the weapon wheel/med patches, and Windows letterbox-only
presentation. Those are not replacements for the Base Village
strip club, Trap House, Motor Works, expanded map or Signal.

L = reload the currently fitted arcade Pulse tool. Tab = weapon
wheel and V = stocked med patch while the wheel is open. Both
are separate from Signal (P/F7) and optional chase view (C).
M = atlas; F8 from the atlas shows the expanded road network.

Save compatibility:
- Rev2–10 retain the established imports.
- 304-byte Rev11 stores a nonzero med-patch count.
- 1,044-byte Rev11 stores expanded features and may also contain a
  med-patch count. It validates its full and base checksums.
- Vendor gear, career, house, club, garage and inner/outer coordinates
  use their original offsets. Older saves do not have to be copied
  into an install folder or started over.
- Keep a backup before moving this save to an older edition. Linux
  automatically retains the original in a hidden compatibility backup
  for the first relevant format change. Windows uses its established
  atomic slot replacement but has no automatic downgrade backup.

Both platforms come from this same source tree: run
  bash scripts/build-linux.sh
  bash scripts/build.sh
and package with python3 scripts/package-crossroads.py.
The active target names are Windows 11 x64 and Linux x86-64;
the Linux build requires glibc 2.34 and SDL2.
