Dead Channel: build on x86-64 Linux

Native Linux:
  bash scripts/build-linux.sh
  bash scripts/test-linux.sh
Output: build/DeadChannel, an x86-64 ELF PIE. GCC builds with the system
SDL2 SDK when it is present and declared by pkg-config; otherwise it uses
the minimal SDL2 x86-64 C ABI declarations and the installed runtime
SONAME libSDL2-2.0.so.0. The distributed ELF's strongest GLIBC symbol
requirement is GLIBC_2.34. Never claim all distros are supported just from
that floor. The test script uses Python 3 and SDL2's dummy video renderer.

Windows x64 cross-build:
  bash scripts/build.sh
  bash scripts/test.sh --tour
Output: build/DeadChannel.exe. Requires GCC, Python 3 and GNU binutils
with i386pep support. The executable is exercised through simulated Win32
on Linux; this is not Wine or a physical Windows test.

Both hosts run the same fixed-step C engine. Do not compile the .inc
files separately. The generated font include is provided; regenerating
it separately requires Pillow and DejaVu fonts. Changing shared host
declarations or save layout requires both platforms' regressions.

The original Easy Entry Hotfix regression tour uses scripts/qa/curb-access-tour.txt.gz. The first
line is the frame count and explicit-save digest, then each line is a
run length and key mask. The Linux test captures before normal quit so
the explicit F5 save can match the Windows test byte for byte, and then
checks the final on-close save independently.
